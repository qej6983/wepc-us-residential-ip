## 先分清你买的是哪种“住宅 IP”

同样挂着“住宅 IP”四个字，市面上的东西差着几倍价钱，付款前必须确认买的是哪一类。

**双 ISP 家宽住宅 IP**：IP 段同时注册在两个 ISP 名下，MaxMind、IPinfo 这类数据库查出来是家庭宽带属性。它本质上是“属性伪装得像家宽”，机房还是在机房里。

**原生 IP**：IP 归属地和机房物理位置一致，比普通机房 IP 干净，但 ISP 属性可能仍是数据中心。解锁流媒体够用，碰上 TikTok、Stripe 这类敏感平台不如双 ISP 家宽。

**真实民房家宽 VDS**：硬件托管在美国民房，IP 由 Atlas Networks、Astound Broadband、T-Mobile/Frontier 这类家庭宽带运营商直接分配，本来就是家宽。过金融风控、长期养号最稳，价格也最贵，丽萨主机这一档 169 元/月起。

**NAT 共享家宽**：共享 IP 加端口映射，价格反而可能最高（丽萨主机纽约 CN2 NAT 共享精简版 599 元/月，只有 4G 硬盘和 100GB 双向流量），属于稀缺资源型产品，普通用户不用考虑。

WePC 美国节点属于第一类和第二类的组合：双 ISP 属性，配 4837 或 9929 回程，价格压在 AUD$12.90 起。它不等同于真实民房 VDS。

## 机房 IP 为什么一登录就被拦

OpenAI 的风控按 IP 归属给风险评级。机房 IP（Datacenter IP）归属写 Hosting、VPS、Cloud，风险最高，绝大多数廉价 VPS 和共享 VPN 出口都在这类；原生 IP 比机房 IP 干净，出身仍是数据中心；住宅 IP 归属真实家庭宽带运营商，在 IP 库里被识别成普通居民用户，评级最低。

这就是买了便宜 VPS 挂上节点，一登录 ChatGPT 跳出 “Access denied”、或者反复做 Cloudflare 人机验证的原因。问题通常出在 IP 归属这一层，不在节点速度。

住宅 IP 能改善三件事：注册 ChatGPT 时不容易触发地区拦截；日常使用少跳验证；同一个 IP 顺带解锁 TikTok、Netflix、Disney+ 这类地域限制服务。但别把它理解成免风控通行证，住宅 IP 标签只降低被判定为机房的概率，账号行为、浏览器指纹、登录频率一样参与风控。

## 常见问题

**双 ISP 和住宅 IP 是一回事吗？**
不完全一样。住宅 IP 指归属是家庭宽带运营商，双 ISP 指 IP 段同时注册在两个 ISP 名下，归属信息更难被判定为机房。WePC 美国节点两个属性都有，但仍然是 VPS，不是民房托管。

**买了就一定能过 ChatGPT 风控吗？**
不能这么承诺。住宅 IP 只降低被识别为机房的概率，账号本身的历史行为、登录环境、操作频率都在风控模型里。预期应该是“验证次数变少”，不是“永远不验证”。

**先月付还是直接年付？**
先月付。IP 干净度、回程稳定性、你本地运营商到该线路的质量，这三件事只有实际用一周才知道。确认没问题再谈年付，年付前先核对流量和硬盘有没有缩水。

**1.5TB 流量够用吗？**
纯 ChatGPT、网页浏览、社媒后台操作，1.5TB 一个月用不完。吃流量的是直播推流、大文件传输、视频缓存。真跑直播，注意看清流量是单向计还是双向计，双向计的实际额度要打对折。

**AUD$12.90 到底合人民币多少？**
按结账当天的澳元汇率算，商店按澳元出账，信用卡或支付宝会按实时汇率折算并可能收取货币转换费。别拿固定数字记住，每次下单前看一眼。
